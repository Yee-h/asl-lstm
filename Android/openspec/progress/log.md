## 2026-04-18 asl-android-app 初始化与一期开发完成

**已完成工作：**
1. 完成了基于 Java 的 Android 项目搭建。
2. 成功集成了 PyTorch Mobile Lite (best_model.ptl) 与 MediaPipe Pose Lite。
3. 实现了 UI 界面：首页、实时识别界面、离线推理界面。
4. 实现了实时摄像头流与离线本地视频文件的读取和接入。

**当前存在的问题（待解决）：**
1. **骨骼点提取错乱问题**：骨骼点的渲染位置和识别与画面中的真实人体不够匹配，或者提取逻辑中前置/后置摄像头的镜像及坐标映射仍存缺陷。
2. **模型准确度问题**：目前送到模型 (est_model.ptl) 的特征张量（x, y, dx, dy）虽然经过了指定的均值方差归一化，但由于 MediaPipe 抽取的关键点序列可能存在抖动，或者我们组装 135 个关键点的维度顺序、缺省值（如左手、右手、面部置 0）和模型训练时的数据分布有差异，导致最终的推理置信度或识别类别不准。

**下一步计划（交接）：**
- 详细对齐 MediaPipe Android 抽取的归一化坐标与训练时 Python 脚本提取的特征对齐逻辑。
- 调试并可视化 dx, dy 和坐标时序缓存（Frame Buffer）的正确性。
- 修复 SkeletonOverlayView 在不同分辨率视频/相机预览流中的缩放偏移。
